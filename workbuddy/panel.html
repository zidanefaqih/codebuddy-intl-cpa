    国际模型设置 Global

    …
    模型 ID名称上下文消耗测试

    模型前缀 — Global

    开启时默认使用 cb/。留空使用默认值，输入其他前缀（如 yes/）可自定义。
    默认: cb/
    ⚠️ 前缀关闭 → 模型 Global 裸 ID（glm-5.3 等）。只要不和 CN 裸 ID 冲突就安全；如果两个 realm 都关，重复 ID（glm-5.3、glm-5.2…）路由会歧义。

    Fallback 模型 missing

    客户端请求不存在/被禁用的模型 → 路由到这里而不是 404。这是名字解析，不是错误恢复。

    硬错误重试 Fallback opt-in

    上游硬失败（403/5xx）且账号 failover 也失败 → 用 Fallback 模型重试 1 次。默认关闭：响应可能来自不同模型（能力与费用不同）；会加 X-WB-Fallback-From 头。
    💡 面板保存的是运行时状态（workbuddy-state.json）。要永久生效：点下方 Copy YAML → 粘贴到宿主 config.yaml。
    更改仅在保存后生效。关闭会丢弃未保存的更改。

    模型前缀 — CN

    开启时默认使用 cn/。留空使用默认值，输入其他前缀（如 yes/）可自定义。
    默认: cn/
    ⚠️ 前缀关闭 → 模型 CN 裸 ID。相同 ID 也存在于 Global（glm-5.3、glm-5.2…）— 路由可能走错 realm，积分倍率不同。

    Fallback 模型 missing

    客户端请求不存在/被禁用的 CN 模型 → 路由到这里而不是 404。

    硬错误重试 Fallback opt-in

    上游硬失败（403/5xx）且账号 failover 也失败 → 用 Fallback 模型重试 1 次。默认关闭。
    💡 面板保存的是运行时状态（workbuddy-state.json）。要永久生效：点下方 Copy YAML → 粘贴到宿主 config.yaml。
    更改仅在保存后生效。关闭会丢弃未保存的更改。
